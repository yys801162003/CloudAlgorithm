# 示例图片

- `upstream_smoke_annotated.jpg`：来自 firewatch 的 `docs/example_2.jpg`，真实照片，**已带上游标注**。本工程神经网络在默认阈值 0.5 下能检出烟雾，最高烟雾候选分数约 0.6765。已有上游框在输入预览中也会出现，并非本工程新增。
- `upstream_mixed_missed_smoke.jpg`：来自同一上游的 `docs/example_3.jpg`，也带已有标注。**该图同时含有火焰和上游烟雾标注。当前模型/阈值下，本工程仅检出火焰，漏检烟雾。它是明确的失败案例，不是无烟阴性样本。** 火焰本身不参与烟雾判定。
- `synthetic_rule_candidate.png`：自行生成的低饱和度纹理，**不是实拍烟雾**。用于观察传统规则为何可能出现误报、以及比较两种方法的差异，不能作为准确率样本。
- `no_smoke_color.jpg`：自行生成的纯色 JPEG，测试文件读取和简单阴性情形。

上游示例照片的来源和 AGPL-3.0 许可见 `../THIRD_PARTY_NOTICES.md`。它们与所用模型来自同一上游，不能作为独立留出测试集。这里只验证接口能读图、运行模型、显示结果，不据此声称准确率。
