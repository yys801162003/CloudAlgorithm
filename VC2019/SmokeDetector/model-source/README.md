# Model training source reference

Files in this directory are unmodified training/export files from `leskoont/firewatch`, revision `b63a106e3554a8cfcdbd491fdde288ec80d3a759`, under that project's AGPL-3.0 license. See the parent `LICENSE-AGPL-3.0.txt` and `THIRD_PARTY_NOTICES.md`.

Complete upstream source, dependency definitions and preparation instructions:
https://github.com/leskoont/firewatch/tree/b63a106e3554a8cfcdbd491fdde288ec80d3a759

The C++ inference application does not execute these Python scripts and needs no Python runtime. Re-training is a separate workflow requiring the upstream dependencies, dataset and compute; no claim of bit-identical retraining is made.
